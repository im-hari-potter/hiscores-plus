Percentile totals

"Top X%" is your rank divided by the number of players ranked in that skill. A skill only appears on the hiscores at level 15, so those counts differ per skill. The counts are refreshed twice a day by the site's GitHub job; this browser refreshes them itself if they get older than a day and a half.

About

Skills+ (formerly Hiscores+) reads the Lost City hiscores API, which allows one request every two seconds, so lookups queue up politely. Hiscores update when a player logs out.

The planner's levels and XP come from Lost City's own server content (rev 274); item names and icons, and the rows of the Crafting calculator, from LostHQ (GPL-3.0); prices from player listings on markets.lostcity.rs. Skill icons and fonts come from LostKit (GPL-3.0); RuneScape is © Jagex.
